# Security Policy

This repository is a private staging area for a future public-facing LDM surface.

## Do not submit sensitive material

Do not commit or attach:

- credentials, tokens, passwords, private keys, keystores, certificates, or signing material;
- `.env` files containing secrets;
- model or `.pte` files;
- golden validation fixtures;
- private evidence bundles, internal parity/conformance harnesses, or private workflow artifacts;
- content copied from the authoritative private repository unless it is explicitly within the approved export boundary.

If sensitive material is discovered, stop further publication work and treat the staging repository as blocked until the exposure is assessed and remediated.

## Security reports

Until this repository is made public, security findings should be handled privately with the repository owner rather than posted in public issues.

Public vulnerability-reporting instructions will be finalized before any visibility change.
